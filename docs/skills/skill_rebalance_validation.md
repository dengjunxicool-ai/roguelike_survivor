## 计量与采样

先以 100P、1000HP 的明确校准夹具验证实际伤害管线：1600 输入 → 有效1000、过量600、DOT1000；真实补盾25、吸收10。对应 `T15-metrics-runtime2`。观测通过可选 root metadata 启用，正常游戏没有采样器。

固定角色 mage、地图 abandoned_dungeon、无永久成长、角色资格等级6、normal品质、基础构筑等级预算12。融合对照预算13：融合Lv1史诗 versus 对照已有技能升一级；基础技能、种子和策略一致。所有15组合使用真实 RequirementPolicy 检查前置。受控初始授予仍是测试入口，不代表自然抽卡路径；抽卡/学习行为另由回归测试覆盖。

场景保持实际敌人数据，常规怪 small_slime、精英 giant_slime、Boss dungeon_heart。固定普通/精英场景停留原地，移动Boss及真实局使用既有避敌/安全拾取/冲刺控制器，拒绝额外升级奖励，不补血。Boss静止攻击阶段只作代理；**真实不可移动Boss未验证**。控制器不是人类玩家，脚本存活率不能解释为玩家胜率。

指标解释：actual_damage 为生命实际损失、overkill 为溢出、status_damage 为status_dot；trigger_count 为通过条件/ICD的通用规则执行，并非每次物理命中，也不覆盖所有原生融合回调；boss_trigger_count 为目标Boss的合格规则执行。buff_uptime 为限时Modifier来源累计存在的 source-seconds，重叠来源分别计入；control_seconds 为冻结敌人秒；generated/absorbed 是本采样窗口的护盾变化，已有护盾可使吸收大于新生成。矩阵的 frame_p95 是物理回调间隔，不用于渲染性能验收。

## 性能

同机 RTX5060、Godot4.6.3、1280×720、mobile渲染、关闭vsync，T0 `6dfee02` 与M4使用字节相同的验证脚本。强制同12技能normal/Lv3，不修改敌人数据。固定24怪维持数量；另运行实际地图前60秒波次。压力采样允许回满玩家生命，仅用于压力测试，**不属于平衡/完整实战**。

真正帧时采用 process_frame 墙钟间隔，先暖机2秒。之前物理帧间隔及并行压力结果均不计入渲染p95验收。`T15-performance/*-frame-serial/data/performance.json` 为有效串行数据；结果如下。16.7ms目标及≤10%退化均须单独判断；60秒波次不能覆盖完整局末段密集压力。

| 同协议场景 | T0 p95 / 样本 | M4 p95 / 样本 | 退化 | 结论 |
| --- | ---: | ---: | ---: | --- |
| 固定24怪 / 12技能 | 2.321ms / 10990 | 3.602ms / 4253 | +55.19% | 16.7ms目标通过，≤10%相对门槛失败 |
| 实际前60s波次 / 12技能 | 1.334ms / 113235 | 1.420ms / 94583 | +6.45% | 两数值门槛通过；完整末段压力仍待测 |

修改前基线本次渲染p95没有超16.7ms。M4固定压力相对退化不满足要求，不能以绝对帧时达标抵消。M4节点峰值1384/1424，敌人峰值24/36，pending峰值18/0。初次physics间隔66.722/24.375ms与真正渲染p95不同，不计渲染门槛。有限观察和现有生命周期/FIFO/复用回归不能证明无限运行没有对象增长或饥饿。原始帧时报告及比较位于T15-performance，晚期高密度全局压力尚未覆盖。
