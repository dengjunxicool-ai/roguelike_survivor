# 火焰神系特效实施计划

沿用已认可的寒霜展示接口，为 14 个基础火焰技能接入程序化材质、明确轮廓和有预算的余烬。伤害、状态、冷却、范围以现有战斗结果为准；不增加特效专用的伤害逻辑。当前共享工作区含用户改动，直接扩展现有接口，保留已有寒霜和霜狼修复。

## 展示映射

| 技能 | 展示 |
| --- | --- |
| 灼热火球 | 明亮热核、火舌尾焰、命中火星和真实燃烧状态 |
| 烈焰疾行 | 沿真实冲刺生成的火径、焦边和上升余烬 |
| 流星火雨 | 陨石热壳、长尾焰、落地冲击与燃烧地面 |
| 熔岩裂涌 | 与真实线形长度、宽度、方向一致的熔岩裂缝 |
| 焚风旋涡 | 随区域移动的旋转火柱与范围底纹 |
| 赤焰龙 | 程序化龙轮廓、翼膜、热核和朝真实攻击目标的吐息 |
| 余烬狐群 | 火狐轮廓、针对实际攻击目标的冲击动画和火花爆燃 |
| 炽燃专注 | 读取真实燃烧层数与持续时间的火焰状态 |
| 过热施法 | 仅实际临时增益有效期间显示角色热浪 |
| 焦土亲和 | 真实火焰地面与燃烧叠加的表现 |
| 燃爆连锁 | 每次真实爆炸位置和半径的冲击波、火团和余烬 |
| 余烬附着 | 跟随实际弹道方向的追踪余烬 |
| 引燃核心 | 确认追加伤害时的紧凑爆燃反馈 |
| 炼狱循环 | 实际死亡爆发与额外陨石共享火焰展示 |

## 接口和预算

年龄由宿主/引擎 delta 推进，禁用 shader TIME 和全局随机数。材质实例隔离；池回收关闭展示，复用时重置年龄/方向/范围。区域只读 geometry_snapshot；召唤物只读实际攻击目标。反馈节点池上限 32，目标反馈节流表上限 128。纹理旧路径保留作为兼容资源。
